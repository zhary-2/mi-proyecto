Mi primer proyecto

Aquí tienes los pasos detallados para subir tu proyecto desde cero a GitHub Pages, usando solo tu navegador web (sin instalar programas). ## Paso 1: Prepara tus archivos * Asegúrate de que tu archivo principal de diseño se llame exactamente index.html (todo en minúsculas). * Guarda todos los archivos de tu página (HTML, CSS, imágenes) juntos en una sola carpeta en tu computadora. ## Paso 2: Crea tu cuenta en GitHub * Entra al sitio web oficial de [GitHub](https://github.com/). * Haz clic en Sign up (Registrarse) en la esquina superior derecha. * Ingresa tu correo electrónico, crea una contraseña y elige un nombre de usuario. * Verifica tu cuenta con el código que llegará a tu correo. ## Paso 3: Crea el contenedor de tu proyecto (Repositorio) * Inicia sesión en GitHub y haz clic en el botón verde New o Create repository (en la esquina superior izquierda). * Escribe un Repository name (Nombre del repositorio), por ejemplo: mi-primer-proyecto. * Asegúrate de seleccionar la opción Public (Público). GitHub Pages no funciona gratis en repositorios privados. * Deja las demás opciones como están y haz clic abajo en el botón verde Create repository. ## Paso 4: Sube tus archivos de código * En la pantalla que aparece, busca y haz clic en el enlace azul que dice uploading an existing file (subir un archivo existente). * Arrastra y suelta todos los archivos y carpetas de tu proyecto dentro del recuadro gris. * Espera a que la barra de carga termine de procesar todos los archivos. * Baja hasta el final de la página y haz clic en el botón verde Commit changes (Confirmar cambios). ## Paso 5: Activa tu página web gratis * Dentro de tu repositorio, haz clic en la pestaña Settings (Configuración), que tiene un ícono de engranaje en la barra superior. * En el menú de la izquierda, busca la sección Code and automation y haz clic en Pages. * En la sección Build and deployment, busca el menú desplegable que dice None bajo la palabra Branch. * Cámbialo por main (o master) y haz clic en el botón Save (Guardar). ## Paso 6: Revisa tu nueva web en internet * Espera de 1 a 2 minutos mientras GitHub procesa los archivos. * Recarga la página de Settings > Pages. * Verás un recuadro superior de color claro con el mensaje: "Your site is live at..." seguido de un enlace azul. * Haz clic en ese enlace y podrás ver tu proyecto publicado en vivo para todo el mundo. Si te trabas en alguno de los pasos, avísame en cuál número vas o descríbeme qué pantalla estás viendo para guiarte en ese punto exacto.
